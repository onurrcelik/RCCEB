# RCCEB documentation

Everything about the member & admin portal and how it ships with the public site rcceb.org. Newest-first reading order for someone new:

1. **[developer-guide.md](developer-guide.md): start here.** What RCCEB is, who's who, accounts and where everything lives, the live membership flow, data state, working rules, pitfalls, open items.
2. **[deployment.md](deployment.md): read before you ship.** Two repos, two Vercel accounts, one domain; how a push goes live; environment variables; running `db:setup` first.
3. **[architecture.md](architecture.md):** how the portal works (database, auth, onboarding, directory, 1-on-1 matching, UI conventions).
4. **[email.md](email.md):** Resend setup, who gets which email, how to check one was sent.
5. **[changelog.md](changelog.md):** what changed and why.
6. **[whatsapp-plan.md](whatsapp-plan.md):** the next step in the membership flow (built in another repo).
7. **[history/join-sync.md](history/join-sync.md):** archive of how rcceb.org/join was connected to the portal.

At the repo root: [`README.md`](../README.md) (setup and layout), [`TODO.md`](../TODO.md) (open tasks and what was done, newest first), [`AGENTS.md`](../AGENTS.md) (Next.js notice, regenerated by `next dev`) and [`CLAUDE.md`](../CLAUDE.md) (what AI coding sessions load automatically).
